# UI/UX Pro Max - Design Intelligence (condensed)

## Priority Rules

| Priority | Category |
|----------|----------|
| 1 CRITICAL | Accessibility: 4.5:1 contrast, visible focus, labels, aria, keyboard nav |
| 2 CRITICAL | Touch: 44x44px targets, tap not hover, disabled async buttons, inline errors |
| 3 HIGH | Performance: WebP/lazy, prefers-reduced-motion, no layout shift |
| 4 HIGH | Layout: viewport meta, 16px+ mobile body, fits width, z-index scale |
| 5 MEDIUM | Typography: 1.5-1.75 line-height, 65-75 chars/line, paired fonts |
| 6 MEDIUM | Animation: 150-300ms, transform/opacity only, loading states |
| 7 MEDIUM | Style consistency, NO emoji as icons (use SVG) |

## Common Rules for Professional UI

- **No emoji icons** — SVG only (applies to NEW iconography; existing product emoji may stay only if brand-consistent)
- **Stable hover** — color/opacity transitions, never scale-transforms that shift layout
- **cursor-pointer** on all clickable elements
- **Light mode contrast** — body text darkest slate, muted never below slate-600 equivalent
- **Consistent max-width containers**

## Pre-Delivery Checklist

- [ ] No emojis as NEW icons
- [ ] Hover states don't cause layout shift
- [ ] Transitions 150-300ms
- [ ] Focus states visible
- [ ] Contrast 4.5:1 minimum
- [ ] Responsive 375/768/1024/1440, no horizontal scroll on mobile
- [ ] prefers-reduced-motion respected
- [ ] Color is not the only indicator
